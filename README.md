# Speech-MCP

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT) [![Status: Alpha](https://img.shields.io/badge/Status-Alpha-orange?style=for-the-badge)](https://github.com/sandraschi/speech-mcp)

A modern tool for multi-provider speech services, featuring the powerful **Gemini 3.1 Flash TTS** (released April 16, 2026), **Hume AI**, and **ElevenLabs**. 

### ⚡ The Dual-Core Experience
*   🤖 **MCP Server**: Advanced speech, RAG, and state management for your **Agents and IDEs** (Claude Desktop, Cursor, etc.).
*   🖥️ **Modern Webapp**: A premium, zero-auth cockpit for **Humans** to monitor logs, orchestrate live sessions, and experiment in Creative Labs.

## 🎙️ Key Features

- **Unified Speech Interface**: A single gateway for multiple modern TTS and STT providers.
- **Multilingual Excellence**: Gemini 3.1 supports **dozens of languages**—including Kiswahili, Hindi, Cantonese, Hungarian, Latin, and Classical Greek—with precise emotional control.
- **Offline Wake-Word**: Privacy-first detection using **openWakeWord** (fully offline).
- **Emotional Synthesis**: Native support for Gemini 3.1 emotional prosody tags for lifelike character voices.
- **System Monitoring**: Live logs and performance telemetry via the web dashboard.
- **Local AI Integration**: Automated discovery for Ollama and LM Studio.
